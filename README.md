# Smart Basketball 🏀

# About this Project:
The user get's to name a player and beat the comuter opponent. The user get's to upgrade the players stats to win the game. 

# How to play:
Enter 1 to play the game. 
Enter 2 to view player stats.
Enter 3 to visit the shop to upgrade the player.
Enter 4 to view career record.
Enter 5 to leave the game.

# Player Physical Characteristics
Height
Speed
Stamina
Strength

# Player Basketbal Skills

Shooting
Rebounding
Defending

Run main.py
